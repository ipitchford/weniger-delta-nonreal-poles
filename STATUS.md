Object: for a positive Borel measure μ on [0, ∞) with infinite support and finite moments μ_ℓ, the Stieltjes function f(z) = ∫(z + t)⁻¹ dμ(t) and Weniger's delta transformation δ_k^{(n)}(β; z) of its asymptotic series. The denominator is Q_k^{(n,β)}(z) = Σ_j C(k, j) (b + j)_{k−1} z^j / μ_{m+j} with b = n + β and m = n + 1, which is equation (26) of the source. The source of the question is R. Borghi, *Is Weniger's transformation capable of simulating the Stieltjes function branch cut?*, Mathematics 14 (2026), no. 2, 376, doi:[10.3390/math14020376](https://doi.org/10.3390/math14020376), Sections 3.1 and 3.3. The manuscript's β is the parameter γ of the published article's equations (23) and (26) (β in the author preprint's equations (26) and (29)).

What the package claims (numbers refer to [paper/paper.pdf](paper/paper.pdf); Table 2 of the manuscript lists the same statuses):

* **Proved in writing.** Every proof is in the manuscript. Some steps are exact polynomial identities, and `code/verify_all.py` checks those.
  * Proposition 2.1 and Theorem 4.1(3): orders one and two are real-rooted for every measure.
  * Theorem 3.2: for fixed positive weights h_j, Σ h_j z^j/μ_{m+j} has only negative real zeros for every admissible measure iff h_j² ≥ 4h_{j−1}h_{j+1} at every internal index. Sufficiency is the Hutchinson–Kurtz criterion (Lemma 3.1); necessity is a realisation lemma isolating three consecutive moments by explicit measures.
  * Theorem 4.1: the complete order–shift classification. At k = 3, safety holds exactly when b ≤ b_c = (√33 − 5)/2; for every k ≥ 4, n ≥ 0 and β > 0 some admissible measure gives a genuine nonreal conjugate pair of poles. The witnesses can have moments ~ c·ℓ! (Carleman, so the moment problem is determinate) and, by Corollary 4.6, a smooth strictly positive density. The measure depends on (k, n, β).
  * Lemma 4.2, Proposition 4.3, Lemmas 4.4–4.5: the nonreal zeros are genuine poles (accuracy through order; deg gcd(P, Q) < ⌈k/2⌉; a one-moment perturbation inside the admissible class).
  * Corollary 5.2: for every fixed n there is one admissible measure giving δ_4^{(n)}(β; ·) a genuine nonreal pair of poles for every β > 0 (a uniform Rouché argument; no explicit constants).
  * Theorem 6.1 and Corollary 6.2: (b)_{k−1}⁻¹ Q_k(w/k²) → E_μ(w) locally uniformly; nonreal zeros of E_μ force nonreal zeros of Q_k at all large k.
  * Theorem 6.3(2): for μ = δ_1 + 50δ_{1/50} + 10⁻³e^{−t}dt, n = 0, β = 1, Q_k has nonreal zeros for every k ≥ k_0. The proof uses one exact certificate (the Jensen polynomial g_6 has two nonreal zeros). k_0 is not effective, and these are denominator zeros: genuineness at large k is not proved.
  * Theorem 7.2 and Corollary 7.3: real-rootedness at every order when P_k is real-rooted, when (1/μ_{m+j}) is a multiplier sequence, or when μ_{r−1}μ_{r+1} ≥ 4μ_r². This covers Γ(ℓ + a) (including the Euler series ℓ!), Γ(νℓ + c) with integer ν and c > 0, Beta weights t^α(1 − t)^p with integer p ≥ 0, and log-normal moments with σ² ≥ 2 log 2. At n = 0, γ = 1 the superfactorial, Laguerre and integer-difference Jacobi cases are Borghi's (his §§4.2, 4.3, 4.6); the corollary extends them to every n, β and k.
  * Remark 7.4: for fixed n, k and measure, Q_k^{(n,β)} is real-rooted for every β > 0 iff Borghi's P_k is real-rooted.
* **Certified by exact computation, for the stated finite cases only** (rational arithmetic, exact Sturm counts, exact gcds; [results/verification.json](results/verification.json)).
  * Section 5: the cubic example (n = 0, β = 1) with a negative 47-digit discriminant and gcd(P̂, Q̂) = 1; the quartic example (n = 0, β = 1/3 < b_c) with a negative Laguerre value at −1 and gcd 1.
  * Proposition 5.1: for λ = δ_1 + 10⁵δ_{1/100} + 10⁻³e^{−t}dt, the discriminant of Q_4 is a degree-18 polynomial in β with all coefficients negative, for n = 0 and n = 1; one nonreal pair of genuine poles for every β > 0. At n = 2 the same measure fails (four negative real zeros at β = 1).
  * Table 3: the tail family at k = 5–8, n ∈ {0, 1}, β ∈ {1/10, 1, 5}, with the smallest K = 2^e, 1 ≤ e ≤ 16.
  * Theorem 6.3(1) and Table 4: for the fixed measure, genuine nonreal poles at every order 3 ≤ k ≤ 30.
  * Section 7, "Exact tests": every Q_k real-rooted on the grid 4 ≤ k ≤ 8, n ∈ {0, 1, 2}, β ∈ {1/10, 1/2, 1, 2, 5} for 15 moment families (975 Sturm counts). For the Weniger–Čížek K_ν moments and the three non-integer Jacobi weights this is evidence on the grid only. After Remark 7.4: the Jacobi weight t^{−1/2}(1 − t)^{1/2} at n = 0, k = 4, β = 20 has a genuine nonreal pair of poles, so the non-integer Jacobi weights are not real-rooted for every shift.
* **Numerical only.** Section 8 and Figure 1: pole coordinates, residues, relative errors, the scaled zeros k²z near the zero w* ≈ −9.1021 + 9.1273i of E_μ, and the accuracy co-occurrence table (its nonreal counts and gcd degrees are exact; the errors are floating point). No causal claim is made.
* **Open.** Conjecture 6.4: genuine nonreal poles at every k ≥ 3 for the fixed measure. Which measures have E_μ in the Laguerre–Pólya class, and whether that suffices at large orders. The Weniger–Čížek K_ν family. Other Levin-type weights (Levin's t and u). An explicit all-shift order-four measure for n ≥ 2 (existence is Corollary 5.2).

Not covered: convergence or divergence of the delta approximants; the asymptotic distribution of poles for natural moment families; other Levin-type transformations. No proof assistant was used.
